CLOUDFLOW REST API DOCUMENTATION
Version: 2.0 | Base URL: https://api.cloudflow.io/v2
=======================================================

AUTHENTICATION
--------------
All API requests require a Bearer token in the Authorization header.
Obtain a token via POST /auth/token with your API key and secret.
Tokens expire after 24 hours. Refresh tokens are valid for 30 days.

Rate Limits:
- Starter: 100 requests/minute
- Professional: 1,000 requests/minute
- Enterprise: 10,000 requests/minute

---

ENDPOINT: POST /auth/token
Description: Authenticate and obtain an access token.
Parameters:
  - api_key (string, required): Your API key from Settings → API Keys
  - api_secret (string, required): Your API secret
  - grant_type (string, optional): Default "client_credentials"
Response: { "access_token": "...", "expires_in": 86400, "token_type": "Bearer" }
Error Codes: 401 Invalid credentials, 429 Rate limit exceeded

---

ENDPOINT: GET /workspaces
Description: List all workspaces accessible to the authenticated user.
Parameters:
  - page (integer, optional): Page number, default 1
  - per_page (integer, optional): Results per page, default 20, max 100
  - sort (string, optional): Sort field: "name", "created_at", "updated_at"
Response: { "data": [...], "total": 42, "page": 1, "per_page": 20 }

---

ENDPOINT: POST /workspaces
Description: Create a new workspace.
Parameters:
  - name (string, required): Workspace name, 1-100 characters
  - description (string, optional): Workspace description
  - visibility (string, optional): "private" (default) or "team"
Response: { "id": "ws_abc123", "name": "...", "created_at": "..." }
Error Codes: 400 Validation error, 403 Plan limit reached

---

ENDPOINT: GET /workspaces/{workspace_id}/documents
Description: List all documents in a workspace.
Parameters:
  - workspace_id (string, required): Workspace ID (path parameter)
  - type (string, optional): Filter by file type: "pdf", "docx", "image", etc.
  - search (string, optional): Full-text search query
  - page (integer, optional): Page number
Response: { "data": [...], "total": 156 }

---

ENDPOINT: POST /workspaces/{workspace_id}/documents
Description: Upload a document to a workspace.
Parameters:
  - workspace_id (string, required): Workspace ID (path parameter)
  - file (binary, required): The file to upload (multipart/form-data)
  - folder_path (string, optional): Destination folder path
  - tags (array of strings, optional): Document tags for organization
Response: { "id": "doc_xyz789", "name": "report.pdf", "size": 1048576 }
Error Codes: 400 Invalid file, 413 File too large, 507 Storage quota exceeded

---

ENDPOINT: GET /workspaces/{workspace_id}/documents/{document_id}
Description: Retrieve document metadata and download URL.
Parameters:
  - workspace_id (string, required): Workspace ID
  - document_id (string, required): Document ID
  - include (string, optional): Comma-separated: "versions", "comments", "permissions"
Response: { "id": "...", "name": "...", "download_url": "...", "metadata": {...} }

---

ENDPOINT: DELETE /workspaces/{workspace_id}/documents/{document_id}
Description: Delete a document. Moves to trash for 30 days before permanent deletion.
Parameters:
  - workspace_id (string, required): Workspace ID
  - document_id (string, required): Document ID
  - permanent (boolean, optional): Skip trash, delete immediately (Enterprise only)
Response: 204 No Content
Error Codes: 403 Insufficient permissions, 404 Document not found

---

ENDPOINT: POST /workspaces/{workspace_id}/ai/summarize
Description: Generate an AI summary of a document or set of documents.
Parameters:
  - workspace_id (string, required): Workspace ID
  - document_ids (array of strings, required): Documents to summarize
  - length (string, optional): "brief" (1-2 sentences), "standard" (1 paragraph), "detailed" (multiple paragraphs)
  - language (string, optional): Output language (ISO 639-1 code), default "en"
Response: { "summary": "...", "key_points": [...], "tokens_used": 1500 }
Error Codes: 400 No documents specified, 402 AI credits exhausted

---

ENDPOINT: POST /workspaces/{workspace_id}/ai/ask
Description: Ask a question about workspace documents using RAG.
Parameters:
  - workspace_id (string, required): Workspace ID
  - question (string, required): The question to answer
  - document_ids (array of strings, optional): Limit search to specific documents
  - max_sources (integer, optional): Maximum source documents to use, default 5
Response: { "answer": "...", "sources": [{"document_id": "...", "excerpt": "..."}] }

---

ENDPOINT: GET /users/me
Description: Get the authenticated user's profile information.
Parameters: None
Response: { "id": "usr_123", "email": "...", "name": "...", "role": "admin", "plan": "professional" }

---

ENDPOINT: POST /webhooks
Description: Register a webhook for event notifications.
Parameters:
  - url (string, required): The webhook endpoint URL (must be HTTPS)
  - events (array of strings, required): Events to subscribe to: "document.created", "document.deleted", "workspace.updated", "user.invited"
  - secret (string, optional): Signing secret for webhook verification
Response: { "id": "wh_456", "url": "...", "events": [...], "active": true }
Error Codes: 400 Invalid URL, 403 Enterprise plan required for some events
